Ghi chú thiết kế (map sang code)

  • 2 nút hành động lớn — Lưu RRS + Reset Data (xanh) và Reset Data / System Clean (đỏ) luôn ở đầu dashboard, bám layout hiện tại.
  • Device status + Selection Center + Management — giữ nguyên luồng: trạng thái máy → hành động → chọn app/fake → quản lý RRS (badge số lượng).
  • Identifier rows — WXValueRow (icon + title + mono value + Copy + switch); advanced gập lại.
  • App cards — icon thật 48pt, badge On/Frozen, 3 chip action; không blur icon nền 30%.
  • Security — InsetGrouped list + WXControlRow; Matrix rain là toggle tùy chọn, không chạy nền mặc định.
  • Tokens — dùng WeaponXTheme (wxBrandBlue / success / danger / matrixGreen) + systemGrouped backgrounds.
  • Giữ navigation — vẫn 2 tab Home + Security trong UITabBarController.
