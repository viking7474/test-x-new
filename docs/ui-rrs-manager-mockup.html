Spec map sang code (PXRRSManagerViewController)

  • Màn 1 List — thay header/footer frame cứng + glyph ☑/☐. Dùng large title, UISearchController, cell reuse, pill “Đã restore” / “NEXT”.
  • Màn 2 Edit — pattern Photos: nav “Đã chọn N”, checkbox tròn, nút Xóa đỏ. Bắt buộc UIAlertController confirm trước onDelete (hiện tại xóa thẳng filesystem).
  • Màn 3 Detail — màn mới (push). Bundle ID + copy, size, dates, IP, note, checksum. Primary = saveCurrentRRSThenRestoreBackupDirectory.
  • Màn 4 Sequence sheet — gộp footer begin/end + presentRRSSequenceModal thành 1 sheet. Segmented: oldestFirst / newestFirst / theo số. NEXT rõ ràng.
  • Swipe — trailing delete (confirm), leading restore.
  • Empty state — khi entries.count == 0.
  • Giữ logic — onDelete / onSaveAndRestore / onSequenceChanged / onNextChanged / onReload không đổi contract.
