## Backup-root proof

The implementation:

1. Creates missing root components.
2. Inspects the requested final component with `lstat`.
3. Rejects a final symbolic link, non-directory, setuid, or setgid root.
4. Canonicalizes with `realpath`.
5. Opens the canonical root with `O_DIRECTORY | O_NOFOLLOW | O_CLOEXEC`.
6. Verifies descriptor type, close-on-exec state, and retained identity.
7. Requires requested-final, canonical-path, and descriptor device/inode/type identity to match.

Normal ancestor aliases such as `/var -> /private/var` remain compatible because authority is transferred to the proven canonical directory.

The exact bundle identifier is retained as the directory component.

## Factory-failure cleanup

If a workspace was created but the factory cannot return a valid object, cleanup occurs only when:

- the retained bundle descriptor still exposes the same workspace device/inode/type;
- the workspace can be opened no-follow;
- namespace and descriptor identities still match;
- enumeration completes;
- the workspace is empty;
- a final namespace identity check still matches.

Only then is `unlinkat(..., AT_REMOVEDIR)` attempted. Unexpected nonempty or identity-changed directories are preserved. Backup root and bundle directory are never removed.
