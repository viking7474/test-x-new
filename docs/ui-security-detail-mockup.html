Map sang code (Security tab)

  • Root — SecurityTabViewController: large title, hero 9/12, 5 section cards InsetGrouped, giữ tabbar 2 tab.
  • WXControlRow — icon màu + title + sub + trailing Switch | value+› | ›. Destructive dùng subtitle cảnh báo, không dùng chữ đỏ cho title thường.
  • Push details — Connection Type, IP Status, Location, Network Data, Device Spoof, App Version, Time, Fix Version, Deep Clean, Domain Blocking (± Canvas/JB optional).
  • Inline toggles — Jailbreak, VPN, Canvas, Network Data master, App Version, Time, Keychain Wipe master, Matrix, Profile Indicator.
  • Confirm — UIAlert 2 nút cho Keychain Wipe / Nuclear clean; toast top sau khi Lưu.
  • Tokens — WeaponXTheme brand/success/danger/warning/matrix + systemGrouped backgrounds (light/dark).
  • Không đổi IA navigation — vẫn Home + Security; Tools ở Home.
